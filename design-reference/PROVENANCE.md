# Public design reference

Observed 7 November 2026 on https://bisq.network/. This captures a single page, not the complete Bisq design system. The homepage uses IBM Plex Sans, green #25b135, neutral light and dark surfaces, restrained corner radii, and generous section spacing.

- Logo: https://bisq.network/images/bisq-logo.svg, copied unmodified to `src/assets/bisq-logo.svg` for this local pilot. Bisq branding and trademark usage should be reviewed before publication.
- CSS reference: https://bisq.network/css/styles.css and https://bisq.network/css/fonts.css. The downloaded copies here are research references only.
- Fonts: the five Latin IBM Plex Sans WOFF2 files in `src/assets/fonts/` are copied unmodified from https://bisq.network/fonts/ as referenced by the public font stylesheet. IBM publishes IBM Plex under the SIL Open Font License 1.1: https://github.com/IBM/plex. The license and copyright notice are included in `public/fonts/OFL.txt`.

The extracted token files are automated observations, not an authoritative or comprehensive design system. The documentation uses darker green for text on light backgrounds to preserve contrast.
