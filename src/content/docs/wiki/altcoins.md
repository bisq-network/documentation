<div class="wiki-recovered-article" lang="en"><p><strong>Altcoins</strong> are a type of <a href="../payment-methods/">payment account</a> on Bisq that use cryptocurrencies to settle BTC trades instead of legacy fiat-based payment methods.</p>&#10;<p>Any altcoin can be traded on Bisq, theoretically, but the most active markets tend to be XMR, ETH, LTC (and of course <a href="../bsq/">BSQ</a>, but "altcoin" may not be a great term for it).</p>&#10;<aside class="wiki-admonition" role="note"><p><strong>Warning</strong></p><p>There is currently an <a href="https://github.com/bisq-network/proposals/issues/166" rel="noopener noreferrer">indefinite hold</a> on adding new altcoins to Bisq.</p>&#10;</aside>&#10;<p>Some altcoins have special, specific requirements for trading. Make sure you read the in-application pop-ups and information, as well as the following articles:</p>&#10;<ul>&#10;<li><a href="../trading-bsq/">Trading BSQ</a></li>&#10;<li><a href="../trading-monero/">Trading Monero</a></li>&#10;<li><a href="../trading-l-btc/">Trading L-BTC</a></li>&#10;</ul>&#10;<p>See also:</p>&#10;<ul>&#10;<li><a href="../creating-a-payment-account/#creating-an-altcoin-account">Creating an altcoin account</a></li>&#10;<li><a href="../altcoins-instant/">Altcoins Instant</a></li>&#10;</ul>&#10;</div>
