**Altcoins** are a type of [payment account](../payment-methods/) on Bisq that use cryptocurrencies to settle BTC trades instead of legacy fiat-based payment methods.

Any altcoin can be traded on Bisq, theoretically, but the most active markets tend to be XMR, ETH, LTC (and of course [BSQ](../bsq/), but \"altcoin\" may not be a great term for it).

<aside class="wiki-admonition" role="note">

**Warning**

There is currently an [indefinite hold](https://github.com/bisq-network/proposals/issues/166) on adding new altcoins to Bisq.

</aside>

Some altcoins have special, specific requirements for trading. Make sure you read the in-application pop-ups and information, as well as the following articles:

- [Trading BSQ](../trading-bsq/)
- [Trading Monero](../trading-monero/)
- [Trading L-BTC](../trading-l-btc/)
