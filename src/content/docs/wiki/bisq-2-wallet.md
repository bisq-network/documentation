<div class="wiki-recovered-article" lang="en"><p>Bisq 1 uses <a href="https://bitcoinj.org/" rel="noopener noreferrer">bitcoinj</a> for it's bitcoin wallet implementation. It is not 100% decided yet which wallet we will use (currently Electrum and Bitcoin core).</p>&#10;<p>Initially Bisq 2 users will be able to use a bitcoin wallet of their choice for trading on Bisq. Users wanting to utilize BSQ will also need to do so through Bisq 1.</p>&#10;<h2 id="bitcoin-wallet"> Bitcoin wallet </h2>&#10;<p>For the initial release of Bisq 2 there will be no integrated Bitcoin wallet.</p>&#10;<p>Users will be able to use their own wallet for trading.</p>&#10;<p>Examples of wallets that can used include:</p>&#10;<ul>&#10;<li><a href="https://bitcoin.org/en/download" rel="noopener noreferrer">Bitcoin Core</a></li>&#10;<li><a href="https://electrum.org/" rel="noopener noreferrer">Electrum</a></li>&#10;<li><a href="https://sparrowwallet.com/" rel="noopener noreferrer">Sparrow</a></li>&#10;</ul>&#10;<p>For more options see the Bitcoin.org <a href="https://bitcoin.org/en/choose-your-wallet" rel="noopener noreferrer">choose your wallet</a> guide.</p>&#10;<h2 id="bsq-wallet"> BSQ wallet </h2>&#10;<p>For the initial release of Bisq 2 there will be no integrated BSQ wallet. Traders wanting to buy, sell, burn, lock, make DAO proposals or vote with BSQ will need to do so through Bisq 1.</p>&#10;</div>
