## Duties {#duties}

- Perform [duties common to all roles](https://docs.bisq.network/roles.html#common-duties)
- Merge pull requests per the [Development Process](../development-process/)
- Manage critical bugs per the [Critical Bugs](../critical-bugs/) process

<span class="wiki-legacy-anchor" id="Rights" aria-hidden="true">

## Rights {#rights}

- Admin access to the bisq-network/bisq repository
- Write access to the [critical bugs board](../critical-bugs/#board)
