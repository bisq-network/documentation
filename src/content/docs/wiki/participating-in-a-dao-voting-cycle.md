<div class="wiki-recovered-article" lang="en"><p><strong>Participating in a DAO voting cycle</strong> is something any stakeholder can do—Bisq trader, contributor, or anyone else who wants to help the project succeed.</p>&#10;<p>This article covers how to make a proposal and vote on other proposals, as well as how the BSQ token enables this process to be handled in a decentralized and trustless but meritocratic way.</p>&#10;<p>For a brief overview of how the Bisq DAO works at a high level, see the <a href="../introduction-to-the-dao/">DAO introduction article</a>.</p>&#10;<span class="wiki-legacy-anchor" id="Background" aria-hidden="true"></span><h2 id="background"> Background </h2>&#10;<p>As covered in the <a href="../introduction-to-the-dao/">Introduction to the DAO</a> article, the Bisq DAO's governance model helps achieve several functions for the Bisq project.</p>&#10;<p>This governance model is composed of voting cycles: periods of 4,679 blocks (approximately 1 month) made of 4 phases:</p>&#10;<ol>&#10;<li><strong>Proposal phase</strong>, in which stakeholders submit compensation requests and other proposals requesting reimbursements for trading fees, changes in trading parameters, or changes in some other aspect of the Bisq project. After the proposal phase is over, there is a break of 150 blocks (about 1 day) to review and discuss proposals before voting begins.</li>&#10;<li><strong>Blind voting phase</strong>, in which stakeholders cast their votes on submitted proposals. Votes are encrypted in this phase to prevent later voters from being influenced by earlier voters. Following the end of the blind voting phase, there is a break of 10 blocks to protect against reorgs.</li>&#10;<li><strong>Vote reveal phase</strong>, in which each stakeholder sends the decryption key for their vote. Again, for protection against reorgs, there is a break of 10 blocks after this phase is over.</li>&#10;<li><strong>Vote result phase</strong>, in which vote results are calculated and BSQ is issued accordingly.</li>&#10;</ol>&#10;<p>You can see approximate start and end dates for the current voting cycle at <code class="wiki-source-code" id="source-code-1">DAO</code> &gt; <code class="wiki-source-code" id="source-code-2">Governance</code> &gt; <code class="wiki-source-code" id="source-code-3">Dashboard</code>.</p>&#10;<figure class="wiki-source-image" id="source-image-1"><a href="../../media/wiki/5b4a9220e56d85177e0429b00809a856b99596b7ca68717429ddac6a6c5d4d16.png"><img alt="DAO blocks and estimated calendar times." decoding="async" height="810" loading="lazy" src="../../media/wiki/5b4a9220e56d85177e0429b00809a856b99596b7ca68717429ddac6a6c5d4d16.png" width="1400"></a><figcaption>DAO blocks and estimated calendar times.<br><small>Historical thumbnail; original resolution not recovered. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>&#10;<span class="wiki-legacy-anchor" id="Acquire_BSQ" aria-hidden="true"></span><h2 id="acquire-bsq"> Acquire BSQ </h2>&#10;<p>In order to participate in DAO voting, you will need BSQ. See how to acquire BSQ <a href="../paying-trading-fees-with-bsq/#acquire-bsq">in this article</a>.</p>&#10;<p>As of this writing, making a proposal costs 2 BSQ and casting a ballot (voting) costs 2 BSQ. You'll also need some plain BTC for transaction fees (each DAO action is a bitcoin transaction which requires mining fees to be paid), and if you will be <a href="../making-a-compensation-request/">asking for compensation</a> or reimbursement, you'll need to include some plain BTC to be colored into BTC (precise amount is 100 satoshis × [requested BSQ amount]).</p>&#10;<p>Keep this in mind when buying BSQ to get started for the first time, and make sure you have a BTC balance in your Bisq wallet that's sufficient for what you want to do.</p>&#10;<span class="wiki-legacy-anchor" id="Make_a_proposal" aria-hidden="true"></span><h2 id="make-a-proposal"> Make a proposal </h2>&#10;<aside class="wiki-admonition" role="note"><p><strong>Note</strong></p><p>Proposals can only be made during the proposal phase. If the voting cycle is in any other phase, you’ll need to wait for the proposal phase of the next voting cycle to make your proposal.</p>&#10;</aside>&#10;<aside class="wiki-admonition" role="note"><p><strong>Note</strong></p><p>The process for making a compensation request is largely the same as the process outlined here, but see <a href="../making-a-compensation-request/">this article</a> for additional considerations.</p>&#10;</aside>&#10;<p><strong>Please read <a href="../proposals/">this article on proposals</a> before submitting a proposal for voting.</strong> Bisq proposals tend to be for significant items, and proposals submitted to the DAO are typically for <a href="../proposals/#submit-to-the-dao-if-needed"></a></p><p><a href="../proposals/#submit-to-the-dao-if-needed"><em>controversial</em> significant items</a></p><a href="../proposals/#submit-to-the-dao-if-needed">&#10;</a>.<p></p>&#10;<p>In <code class="wiki-source-code" id="source-code-4">DAO</code> &gt; <code class="wiki-source-code" id="source-code-5">Governance</code> &gt; <code class="wiki-source-code" id="source-code-6">Make Proposal</code>, you’ll find the form to make a new proposal. Pick the type of proposal you want to make from the dropdown, fill the form, and hit <code class="wiki-source-code" id="source-code-7">Make Proposal</code>.</p>&#10;<ul>&#10;<li>Make sure the GitHub handle you put in Bisq matches the GitHub handle on the issue.</li>&#10;<li>Also make sure to replace <code class="wiki-source-code" id="source-code-8">#</code> with the GitHub proposal number. For example, if submitting proposal #999 with URL <a href="https://github.com/bisq-network/proposals/issues/999" rel="noopener noreferrer">https://github.com/bisq-network/proposals/issues/999</a>, the DAO proposal URL should be <a href="https://bisq.network/dao-proposals/999" rel="noopener noreferrer">https://bisq.network/dao-proposals/999</a>.</li>&#10;</ul>&#10;<aside class="wiki-admonition" role="note"><p><strong>Warning</strong></p><p>Beware that proposals cannot be edited after being submitted. If you need to make a change, you can delete the proposal and make a new one while the proposal phase is still active, but you’ll need to pay the proposal fee again. Once the proposal phase is over, proposals cannot be added or removed until the next proposal phase.</p>&#10;</aside>&#10;<p>Here's how making a generic proposal can look:</p>&#10;<figure class="wiki-source-image" id="source-image-2"><a href="../../media/wiki/3b2d88889e9ce2e02a2bbfda0c272d116204049d656a30e5aff090ce078e9c55.png"><img alt="Submit a generic proposal for DAO voting." decoding="async" height="825" loading="lazy" src="../../media/wiki/3b2d88889e9ce2e02a2bbfda0c272d116204049d656a30e5aff090ce078e9c55.png" width="1400"></a><figcaption>Submit a generic proposal for DAO voting.<br><small>Historical thumbnail; original resolution not recovered. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>&#10;<span class="wiki-legacy-anchor" id="Vote_on_proposals" aria-hidden="true"></span><h2 id="vote-on-proposals"> Vote on proposals </h2>&#10;<p>Once the proposal phase is over, after a short break, the voting phase starts.</p>&#10;<p>You can see all proposals in the current voting cycle in <code class="wiki-source-code" id="source-code-9">DAO</code> &gt; <code class="wiki-source-code" id="source-code-10">Governance</code> &gt; <code class="wiki-source-code" id="source-code-11">Browse Open Proposals</code>.</p>&#10;<p>Click through each proposal to see more details, and then vote—it’s strongly recommended that you only accept or reject proposals you know well and have a strong opinion about.</p>&#10;<figure class="wiki-source-image" id="source-image-3"><a href="../../media/wiki/aedc2d277b0573b0f6c253a7f440f64358facffd16b1ef7f80a87f125b170c1f.png"><img alt="Cast votes for proposals during the blind voting phase." decoding="async" height="640" loading="lazy" src="../../media/wiki/aedc2d277b0573b0f6c253a7f440f64358facffd16b1ef7f80a87f125b170c1f.png" width="888"></a><figcaption>Cast votes for proposals during the blind voting phase.<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>&#10;<span class="wiki-legacy-anchor" id="Submit_votes" aria-hidden="true"></span><h2 id="submit-votes"> Submit votes </h2>&#10;<p>When you’re done selecting your votes, you will need to submit your votes.</p>&#10;<figure class="wiki-source-image" id="source-image-4"><a href="../../media/wiki/121d495dc99f76bf055473c89a6175b58dac4dca88298f0dccef2697a50cac43.png"><img alt="Select voting weight and submit all votes." decoding="async" height="512" loading="lazy" src="../../media/wiki/121d495dc99f76bf055473c89a6175b58dac4dca88298f0dccef2697a50cac43.png" width="809"></a><figcaption>Select voting weight and submit all votes.<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p>All votes are submitted in a single ballot. Casting a ballot currently costs 2 BSQ + mining fees.</p>&#10;<p>In addition, to submit your votes, you need to specify a BSQ amount to use for <strong>voting stake</strong>. The more BSQ you stake for your vote, the more weight it will carry. This staked BSQ cannot be traded or otherwise transferred until your vote reveal transaction is published.</p>&#10;<p>The software has checks to prevent such BSQ from being spent, but if BSQ staked for voting is somehow spent, the corresponding vote will be rendered invalid.</p>&#10;<p>This is why, as you see in the screenshot to the left, it's advisable to use most (but not all) of your BSQ for the voting stake—we left some BSQ available for spending in case we need it for other purposes during the remainder of the voting cycle.</p>&#10;<p><code class="wiki-source-code" id="source-code-12">Vote weight from earned BSQ</code> is BSQ earned from contributing to Bisq: this BSQ is treated slightly differently from BSQ bought on the open market when determining a stakeholder’s voting weight.</p>&#10;<aside class="wiki-admonition" role="note"><p><strong>Note</strong></p><p>For more details on how voting weight is determined, see the <a href="../dao-user-reference/#voting-stake">DAO user reference</a>.</p>&#10;</aside>&#10;<p>Once you’ve entered a voting stake, go ahead and click <code class="wiki-source-code" id="source-code-13">Vote on all proposals</code>.</p>&#10;<span class="wiki-legacy-anchor" id="Reveal_your_vote" aria-hidden="true"></span><h2 id="reveal-your-vote"> Reveal your vote </h2>&#10;<p>After the blind voting phase is over, you must make sure Bisq goes back online at some point during the vote reveal phase to publish your vote reveal transaction.</p>&#10;<p>Bisq will publish the transaction automatically when it’s online, so you don’t have to actually do anything, and you’ll see a pop-up when the transaction is published.</p>&#10;<p>This transaction includes the key to decrypt your vote from the blind voting phase. It also includes a representation of all votes you’ve received from the network, which is used to determine a consensus of all votes cast on the network. See more details <a href="../dao-user-reference/#vote-reveal-phase">here</a>.</p>&#10;<p><strong>Don’t forget this step! If your vote reveal transaction is not published, your vote cannot be decrypted, and so it cannot be counted.</strong></p>&#10;<span class="wiki-legacy-anchor" id="Get_vote_results" aria-hidden="true"></span><h2 id="get-vote-results"> Get vote results </h2>&#10;<p>Once the vote reveal phase is over, results are calculated and the next voting cycle starts.</p>&#10;<p>You can see results of the last voting cycle in <code class="wiki-source-code" id="source-code-14">DAO</code> &gt; <code class="wiki-source-code" id="source-code-15">Governance</code> &gt; <code class="wiki-source-code" id="source-code-16">Vote Results</code>.</p>&#10;<figure class="wiki-source-image" id="source-image-5"><a href="../../media/wiki/153abbc447ab34ed713dbdffb3324a59bfbf67ee82e28f190cddd58ddf4cc2cb.png"><img alt="Submit a generic proposal for DAO voting." decoding="async" height="708" loading="lazy" src="../../media/wiki/153abbc447ab34ed713dbdffb3324a59bfbf67ee82e28f190cddd58ddf4cc2cb.png" width="1196"></a><figcaption>Submit a generic proposal for DAO voting.<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>&#10;<span class="wiki-legacy-anchor" id="See_DAO_transactions_on_a_block_explorer" aria-hidden="true"></span><h2 id="see-dao-transactions-on-a-block-explorer"> See DAO transactions on a block explorer </h2>&#10;<p>Since DAO transactions are bitcoin transactions, you can see them on any bitcoin block explorer. But because transactions use BSQ (bitcoin colored in a way that only Bisq understands), ordinary bitcoin block explorers can’t recognize which bitcoin transactions are also BSQ transactions.</p>&#10;<p>Hence <a href="https://explorer.bisq.network" rel="noopener noreferrer">BSQ block explorers</a>. Whenever you do a Bisq DAO transaction, including paying trading fees with BSQ, you can see it on a BSQ block explorer.</p>&#10;<p>Here’s a screenshot of the past few BSQ transactions that took place at the end of Cycle 23:</p>&#10;<figure class="wiki-source-image" id="source-image-6"><a href="../../media/wiki/51f1696fa51645f3527349521205a00a0171c2c2de4977adbabdf9cf8c325c8f.png"><img alt="A listing of Bisq DAO transactions on mempool.space." decoding="async" height="961" loading="lazy" src="../../media/wiki/51f1696fa51645f3527349521205a00a0171c2c2de4977adbabdf9cf8c325c8f.png" width="1400"></a><figcaption>A listing of Bisq DAO transactions on mempool.space.<br><small>Historical thumbnail; original resolution not recovered. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>&#10;</div>
