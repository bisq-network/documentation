## Updating Bisq {#updating-bisq}

Almost every [Cycle](../participating-in-a-dao-voting-cycle/#background), a new Bisq version is released, with new features and bug fixes. It\'s highly recommended to keep Bisq updated to [last version](https://github.com/bisq-network/bisq/releases/), as not doing so could lead to bugs and other issues.\
Updating Bisq simply requires to install the new version over the existing one. Before updating, it\'s recommended to make a [backup](../backing-up-application-data/).

<aside class="wiki-admonition" role="note">

**Warning**

Do not downgrade Bisq. Installing an older version could cause irreversible damage to Bisq data.

</aside>

## Notification {#notification}

To inform users that a new version is ready and eliminate the need to manually verify the downloaded files, a popup will appear when a new version is released.

<figure class="wiki-source-image" id="source-image-1"><a href="../../media/wiki/a9e16d42dc98e43f2bd804d78815c69fc969d7b029c5b61ce08beaffa6c6059a.png"><img alt="Updating bisq popup.png" decoding="async" height="405" loading="lazy" src="../../media/wiki/a9e16d42dc98e43f2bd804d78815c69fc969d7b029c5b61ce08beaffa6c6059a.png" width="890"></a><figcaption>Updating bisq popup.png<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>

Clicking on *download installer and verify signature* will download the files needed to install Bisq and will automatically verify that the signatures are correct.\
The files to install Bisq should be ready at *Downloads* folder to be [installed](../downloading-and-installing/).

## Activate pre-release notifications {#activate-pre-release-notifications}

Some users might want to help testing a pre-release version a in real environment. To be notified when a pre-release is ready, go to *Settings* and activate the *Receive pre-release notifications* toggle.
