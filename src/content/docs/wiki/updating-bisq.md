<div class="wiki-recovered-article" lang="en"><h2 id="updating-bisq"> Updating Bisq </h2>&#10;<p>Almost every <a href="../participating-in-a-dao-voting-cycle/#background">Cycle</a>, a new Bisq version is released, with new features and bug fixes. It's highly recommended to keep Bisq updated to <a href="https://github.com/bisq-network/bisq/releases/" rel="noopener noreferrer">last version</a>, as not doing so could lead to bugs and other issues.<br>&#10;Updating Bisq simply requires to install the new version over the existing one. Before updating, it's recommended to make a <a href="../backing-up-application-data/">backup</a>.</p>&#10;<aside class="wiki-admonition" role="note"><p><strong>Warning</strong></p><p>Do not downgrade Bisq. Installing an older version could cause irreversible damage to Bisq data.</p>&#10;</aside>&#10;<h2 id="notification"> Notification </h2>&#10;<p>To inform users that a new version is ready and eliminate the need to manually verify the downloaded files, a popup will appear when a new version is released.</p>&#10;<figure class="wiki-source-image" id="source-image-1"><a href="../../media/wiki/a9e16d42dc98e43f2bd804d78815c69fc969d7b029c5b61ce08beaffa6c6059a.png"><img alt="Updating bisq popup.png" decoding="async" height="405" loading="lazy" src="../../media/wiki/a9e16d42dc98e43f2bd804d78815c69fc969d7b029c5b61ce08beaffa6c6059a.png" width="890"></a><figcaption>Updating bisq popup.png<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>&#10;<p>Clicking on <em>download installer and verify signature</em> will download the files needed to install Bisq and will automatically verify that the signatures are correct.<br>&#10;The files to install Bisq should be ready at <em>Downloads</em> folder to be <a href="../downloading-and-installing/">installed</a>.</p>&#10;<h2 id="activate-pre-release-notifications"> Activate pre-release notifications </h2>&#10;<p>Some users might want to help testing a pre-release version a in real environment. To be notified when a pre-release is ready, go to <em>Settings</em> and activate the <em>Receive pre-release notifications</em> toggle.</p>&#10;</div>
