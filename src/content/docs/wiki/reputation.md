<div class="wiki-recovered-article" lang="en"><span class="wiki-legacy-anchor" id="Reputation_in_Bisq_Easy" aria-hidden="true"></span><h2 id="reputation-in-bisq-easy"> Reputation in Bisq Easy </h2>&#10;<p>Reputation is a cornerstone of the security model in <strong><a href="../bisq-easy/">Bisq Easy</a></strong>, a <a href="../bisq-2/">Bisq 2</a> trade protocol. As buyers send their fiat payment <em>before</em> receiving Bitcoin, the seller's reputation provides the trust needed for the buyer to proceed confidently.</p>&#10;<aside class="wiki-admonition" role="note"><p><strong>Warning</strong></p><p><strong>Important Version Requirement:</strong> Please note that due to security updates, active trading on the Bisq network requires using software <strong>version 2.1.6 or higher</strong>. The reputation system described here applies to users on compatible versions participating in the <a href="../bisq-easy/">Bisq Easy</a> protocol.</p>&#10;</aside>&#10;<figure class="wiki-source-image" id="source-image-1"><a href="../../media/wiki/bc9d43f3ea31feccaece81b71a83d09bae88a4c99c08bc11b6b5be24ff1ee3ea.png"><img alt="The 'Build reputation' screen in Bisq 2 (accessed via 'Reputation' on the left menu), showing the four methods available." decoding="async" height="2560" loading="lazy" src="../../media/wiki/bc9d43f3ea31feccaece81b71a83d09bae88a4c99c08bc11b6b5be24ff1ee3ea.png" width="4096"></a><figcaption>The 'Build reputation' screen in Bisq 2 (accessed via 'Reputation' on the left menu), showing the four methods available.<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p><br>&#10;</p>&#10;<span class="wiki-legacy-anchor" id="Why_Reputation_Matters" aria-hidden="true"></span><h3 id="why-reputation-matters"> Why Reputation Matters </h3>&#10;<ul>&#10;<li><strong>For Buyers:</strong> Carefully review a seller's reputation (shown as stars) before accepting an offer. Choosing sellers with a higher reputation is crucial for minimizing trade risks.</li>&#10;<li><strong>For Sellers:</strong> Building and maintaining a high reputation is essential. It increases buyer trust, makes your offers more attractive, helps you get more trades, and allows you to offer larger trade amounts. Maximizing reputation is key to success as a seller on <a href="../bisq-easy/">Bisq Easy</a>. There is expected to be competition among sellers to achieve higher reputation scores.</li>&#10;</ul>&#10;<span class="wiki-legacy-anchor" id="Reputation_&amp;_Trade_Rules_(Version_2.1.1_and_Later)" aria-hidden="true"></span><h3 id="reputation-trade-rules-version-2-1-1-and-later"> Reputation &amp; Trade Rules (Version 2.1.1 and Later) </h3>&#10;<p>Starting with <strong><a href="../bisq-2/">Bisq 2</a> version 2.1.1</strong>, several important rules link reputation directly to trading activity (within the currently required software version):</p>&#10;<ul>&#10;<li><strong>Seller's Maximum Trade Amount:</strong> The maximum amount a seller can offer in a single trade now directly depends on their reputation score. Higher reputation allows sellers to create offers for larger amounts.</li>&#10;<li><strong>System Trade Limits:</strong> While a seller's maximum depends on their reputation, the overall limits for <em>any</em> <a href="../bisq-easy/">Bisq Easy</a> trade are fixed between the fiat equivalent of <strong>6 USD</strong> (minimum) and <strong>600 USD</strong> (maximum). This avoids issues with Bitcoin price swings. (Note: Before v2.1.1, limits were 0.0001 - 0.01 BTC).</li>&#10;<li><strong>Enhanced BSQ Value:</strong> To reward commitment and long-term participation, <a href="../introduction-to-the-dao/">BSQ</a> that is <strong>burned</strong> or <strong>bonded</strong> for reputation now contributes <strong>double its initial value</strong> to the score over the course of the first year (the score increases linearly during that year). This allows sellers to increase their eligible trade limits more quickly.</li>&#10;<li><strong>Minimum Score Setting Removed:</strong> The previous option for buyers to set a specific minimum required reputation score for sellers (formerly defaulted to 30000) was removed in v2.1.1. The system now relies on the direct link between reputation and the allowed trade amount as a better way to handle risk.</li>&#10;</ul>&#10;<figure class="wiki-source-image" id="source-image-2"><a href="../../media/wiki/874ce21a59286f634d28b4917da11e9aa40fc159122654178590bbd7b18870da.png"><img alt="General Bisq Easy trade limits are 6 USD to 600 USD (or fiat equivalent). A seller's specific maximum offer size within this range depends on their reputation." decoding="async" height="1596" loading="lazy" src="../../media/wiki/874ce21a59286f634d28b4917da11e9aa40fc159122654178590bbd7b18870da.png" width="2136"></a><figcaption><p>General <a href="../bisq-easy/">Bisq Easy</a> trade limits are 6 USD to 600 USD (or fiat equivalent). A seller's specific maximum offer size within this range depends on their reputation.</p>&#10;<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<figure class="wiki-source-image" id="source-image-3"><a href="../../media/wiki/aba76dfb345273634505845f61e2f1cc7f91adac7962130de89e2398ad6ce590.png"><img alt="Previously, Bisq warned if trading below a set minimum score; this setting was removed in v2.1.1." decoding="async" height="1596" loading="lazy" src="../../media/wiki/aba76dfb345273634505845f61e2f1cc7f91adac7962130de89e2398ad6ce590.png" width="2136"></a><figcaption>Previously, Bisq warned if trading below a set minimum score; this setting was removed in v2.1.1.<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p><br>&#10;</p>&#10;<span class="wiki-legacy-anchor" id="Understanding_Reputation_Stars" aria-hidden="true"></span><h3 id="understanding-reputation-stars"> Understanding Reputation Stars </h3>&#10;<p>To make reputation easy to compare quickly, <a href="../bisq-easy/">Bisq Easy</a> displays scores using a simple <strong>0 to 5 star system</strong>.</p>&#10;<figure class="wiki-source-image" id="source-image-4"><a href="../../media/wiki/487b180fd114aa377eff356e141ed66650ea58235b1d56ac356054fcabfc3900.png"><img alt="The star system (0-5) provides an easy comparison of seller reputation based on their current rank among active users. 5 stars indicate the highest relative reputation." decoding="async" height="598" loading="lazy" src="../../media/wiki/487b180fd114aa377eff356e141ed66650ea58235b1d56ac356054fcabfc3900.png" width="1601"></a><figcaption>The star system (0-5) provides an easy comparison of seller reputation based on their current rank among active users. 5 stars indicate the highest relative reputation.<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<ul>&#10;<li><strong>How it Works (Relative Ranking):</strong> Your star rating shows how your reputation <strong>compares to all other *active* users</strong> on the Bisq network at that moment. It's your current rank, not a fixed score. The highest-ranked active sellers get 5 stars, the lowest get 0 stars.</li>&#10;<li><strong>Why Stars Change (Dynamic):</strong> Because it's a relative system based on active users, your star rating can change even if your score hasn't:</li>&#10;</ul>&#10;<dl>&#10;<dt></dt>&#10;<dd>&#10;<strong>User Inactivity:</strong> If a user is inactive for <strong>two weeks</strong>, their profile is temporarily excluded from the ranking calculation. If a high-ranked user becomes inactive, others might see their star ratings go up.&#10;</dd>&#10;<dd>&#10;<strong>User Reactivation:</strong> When an inactive user returns, their reputation is factored back in, potentially shifting star ratings again.&#10;</dd>&#10;</dl>&#10;<p><strong>In short:</strong> Stars give you a quick, dynamic view of a seller's current reputation rank compared to their active peers. The star display will change over time based on both your own score changes and the changing scores of other active users.<br>&#10;</p>&#10;<span class="wiki-legacy-anchor" id="How_to_Build_Reputation" aria-hidden="true"></span><h2 id="how-to-build-reputation"> How to Build Reputation </h2>&#10;<p>You can build your reputation score in <a href="../bisq-easy/">Bisq Easy</a> using four methods, accessed via the <strong>`Reputation`</strong> section on the main left-hand menu in Bisq 2. Your <strong>total reputation score</strong> is calculated as the <strong>sum</strong> of the points gained from all methods you use. This total score determines your reputation rank (stars) and your maximum trade offer size.</p>&#10;<p>Reputation scores can change over time: points from <a href="../introduction-to-the-dao/">BSQ</a> Bonds are lost when unlocked, but you can burn or bond <a href="../introduction-to-the-dao/">BSQ</a> repeatedly. You can also import account age or signed account age, potentially replacing previous imported scores if the new import source is older.</p>&#10;<p><br>&#10;</p>&#10;<span class="wiki-legacy-anchor" id="Method_1:_Burning_BSQ" aria-hidden="true"></span><h3 id="method-1-burning-bsq"> Method 1: Burning BSQ </h3>&#10;<p>You permanently <strong>burn</strong> <a href="../introduction-to-the-dao/">BSQ</a> tokens to gain reputation. This represents a strong, long-term commitment to the network, akin to a proof of work. Follow the process displayed in the Bisq 2 Reputation section:</p>&#10;<ol>&#10;<li><strong>Step 1:</strong> Select the user profile in Bisq 2 for which you want to attach the reputation.</li>&#10;<li><strong>Step 2:</strong> Copy the <strong>Profile ID</strong> displayed. You will paste this into Bisq 1.</li>&#10;<li><strong>Step 3:</strong> Open <strong><a href="../bisq-1/">Bisq 1</a></strong> and go to `DAO` &gt; `PROOF OF BURN`. Paste the copied Profile ID into the <strong>`pre-image`</strong> field.</li>&#10;<li><strong>Step 4:</strong> Enter the amount of <a href="../introduction-to-the-dao/">BSQ</a> you want to burn.</li>&#10;<li><strong>Step 5:</strong> Publish the Burn <a href="../bsq/">BSQ</a> transaction.</li>&#10;<li><strong>Step 6:</strong> After blockchain confirmation your reputation will become visible in your Bisq 2 profile.</li>&#10;</ol>&#10;<p><strong>Scoring Details:</strong></p>&#10;<ul>&#10;<li><strong>Initial Score:</strong> <strong>100 points</strong> per <a href="../introduction-to-the-dao/">BSQ</a> burned (Weight = 100).</li>&#10;<li><strong>12-Month Bonus:</strong> The score <strong>doubles</strong> over the first year (increasing linearly from 100 to 200 points per <a href="../introduction-to-the-dao/">BSQ</a> burned). This rewards long-term sellers.</li>&#10;<li><strong>Persistence:</strong> Reputation from burning <a href="../introduction-to-the-dao/">BSQ</a> is permanent for that profile (unless the profile is banned).</li>&#10;<li><strong>Cumulative:</strong> You can burn <a href="../introduction-to-the-dao/">BSQ</a> multiple times; scores add up.</li>&#10;<li><strong>Minimum Burn:</strong> 5.46 <a href="../introduction-to-the-dao/">BSQ</a> (dust limit).</li>&#10;<li><strong>Oracle Publishing:</strong> Data about burned <a href="../introduction-to-the-dao/">BSQ</a> is automatically published by the <a href="../bisq-2-roles/">oracle</a>.</li>&#10;</ul>&#10;<figure class="wiki-source-image" id="source-image-5"><a href="../../media/wiki/9a32933305126ddcb0b9f53b2d74b681c3b434bb9d707930f73b17315e38e130.png"><img alt="Burning BSQ in Bisq 1 requires your Bisq 2 Profile ID as the 'pre-image'." decoding="async" height="377" loading="lazy" src="../../media/wiki/9a32933305126ddcb0b9f53b2d74b681c3b434bb9d707930f73b17315e38e130.png" width="568"></a><figcaption><p>Burning <a href="../introduction-to-the-dao/">BSQ</a> in <a href="../bisq-1/">Bisq 1</a> requires your <a href="../bisq-2/">Bisq 2</a> Profile ID as the 'pre-image'.</p>&#10;<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p><br>&#10;</p>&#10;<span class="wiki-legacy-anchor" id="Method_2:_Bonding_BSQ" aria-hidden="true"></span><h3 id="method-2-bonding-bsq"> Method 2: Bonding BSQ </h3>&#10;<p>You lock up <a href="../introduction-to-the-dao/">BSQ</a> tokens for a set period (minimum ~1 year) to gain reputation. This is refundable, but shows commitment for the lock duration. Like burning, regular bonding can represent user activity. Follow the process displayed in the Bisq 2 Reputation section:</p>&#10;<ol>&#10;<li><strong>Step 1:</strong> Select the user profile in Bisq 2 for which you want to attach the reputation.</li>&#10;<li><strong>Step 2:</strong> Copy the <strong>Profile ID</strong> displayed. You will paste this into Bisq 1.</li>&#10;<li><strong>Step 3:</strong> Open <strong><a href="../bisq-1/">Bisq 1</a></strong> and go to `DAO` &gt; `BONDING` &gt; `BONDED REPUTATION`. Paste the copied Profile ID into the <strong>`salt`</strong> field.</li>&#10;<li><strong>Step 4:</strong> Enter the amount of <a href="../introduction-to-the-dao/">BSQ</a> you want to lock up and the lock time (minimum <strong>`50000`</strong> blocks).</li>&#10;<li><strong>Step 5:</strong> Publish the lockup transaction.</li>&#10;<li><strong>Step 6:</strong> After blockchain confirmation your reputation will become visible in your Bisq 2 profile.</li>&#10;</ol>&#10;<p><strong>Scoring Details:</strong></p>&#10;<ul>&#10;<li><strong>Initial Score:</strong> <strong>10 points</strong> per <a href="../introduction-to-the-dao/">BSQ</a> bonded (Weight = 10).</li>&#10;<li><strong>12-Month Bonus:</strong> The score <strong>doubles</strong> over the first year (increasing linearly from 10 to 20 points per <a href="../introduction-to-the-dao/">BSQ</a> bonded during the lock period).</li>&#10;<li><strong>Persistence:</strong> Reputation lasts only <strong>while the <a href="../introduction-to-the-dao/">BSQ</a> remains bonded</strong>. You lose these points when you unlock the bond.</li>&#10;<li><strong>Cumulative:</strong> You can create multiple bonds; scores add up while active.</li>&#10;<li><strong>Minimum Lock Time:</strong> 50,000 Bitcoin blocks (approximately 1 year).</li>&#10;<li><strong>Confiscation Risk:</strong> In severe cases (like proven scamming), the Bisq <a href="../introduction-to-the-dao/">DAO</a> can vote to confiscate (destroy) a user's bond. Confiscating requires high voter turnout (quorum) in the <a href="../introduction-to-the-dao/">DAO</a>, making it somewhat difficult but possible.</li>&#10;<li><strong>Oracle Publishing:</strong> Data about bonded <a href="../introduction-to-the-dao/">BSQ</a> is automatically published by the <a href="../bisq-2-roles/">oracle</a>.</li>&#10;</ul>&#10;<figure class="wiki-source-image" id="source-image-6"><a href="../../media/wiki/6e8ca2d1433888fd629fda4cefbd424c457f469368701baf5034a6fe3f4f9679.png"><img alt="Bonding BSQ in Bisq 1 uses your Bisq 2 Profile ID as the 'salt'." decoding="async" height="386" loading="lazy" src="../../media/wiki/6e8ca2d1433888fd629fda4cefbd424c457f469368701baf5034a6fe3f4f9679.png" width="567"></a><figcaption><p>Bonding <a href="../introduction-to-the-dao/">BSQ</a> in <a href="../bisq-1/">Bisq 1</a> uses your <a href="../bisq-2/">Bisq 2</a> Profile ID as the 'salt'.</p>&#10;<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p><br>&#10;</p>&#10;<span class="wiki-legacy-anchor" id="Method_3:_Importing_Bisq_1_Account_Age" aria-hidden="true"></span><h3 id="method-3-importing-bisq-1-account-age"> Method 3: Importing Bisq 1 Account Age </h3>&#10;<p>Leverage the history of your fiat accounts from <a href="../bisq-1/">Bisq 1</a>. The older the account, the more trustworthy the user is assumed to be (though this is considered a weaker form of reputation). Follow the process displayed in the Bisq 2 Reputation section:</p>&#10;<ol>&#10;<li><strong>Step 1:</strong> Select the user profile in Bisq 2 for which you want to attach the reputation.</li>&#10;<li><strong>Step 2:</strong> Copy the <strong>Profile ID</strong> displayed. You will paste this into Bisq 1.</li>&#10;<li><strong>Step 3:</strong> Open <strong><a href="../bisq-1/">Bisq 1</a></strong> and go to `ACCOUNT` &gt; `NATIONAL CURRENCY ACCOUNTS`.&#10;<ol>&#10;<li>Select the oldest account you wish to use.</li>&#10;<li>Click the button <strong>`EXPORT ACCOUNT AGE FOR BISQ 2`</strong>.</li>&#10;<li>This copies the required JSON data (containing the proof signed with your Bisq 2 Profile ID) to your clipboard.</li>&#10;</ol></li>&#10;<li><strong>Step 4:</strong> Return to Bisq 2 and paste the JSON data from your clipboard into the text area provided ('Json data from Bisq 1').</li>&#10;<li><strong>Step 5:</strong> Click the <strong>`Request authorization`</strong> button.</li>&#10;</ol>&#10;<p><strong>Scoring Details:</strong></p>&#10;<ul>&#10;<li><strong>Score:</strong> <strong>4 points</strong> per day of the account's age (Weight = 4).</li>&#10;<li><strong>Maximum Age Counted:</strong> 2000 days.</li>&#10;<li><strong>Maximum Score:</strong> Capped at <strong>8,000 points</strong> (4 points/day * 2000 days).</li>&#10;<li><strong>Which Account:</strong> Uses the age of your single <strong>oldest</strong> <a href="../bisq-1/">Bisq 1</a> fiat account. Scores from multiple accounts are <strong>not</strong> added together. Importing from an older account later can replace a previous score from this method.</li>&#10;<li><strong>Limitation:</strong> Account age alone is usually <strong>not enough</strong> for significant reputation; combine with other methods.</li>&#10;</ul>&#10;<figure class="wiki-source-image" id="source-image-7"><a href="../../media/wiki/80e4d249850288f1032f7ebdb76bbab9c2ee2c7664a488783e836d4357904490.png"><img alt="Importing account age involves exporting proof from Bisq 1." decoding="async" height="427" loading="lazy" src="../../media/wiki/80e4d249850288f1032f7ebdb76bbab9c2ee2c7664a488783e836d4357904490.png" width="560"></a><figcaption><p>Importing account age involves exporting proof from <a href="../bisq-1/">Bisq 1</a>.</p>&#10;<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p><br>&#10;</p>&#10;<span class="wiki-legacy-anchor" id="Method_4:_Importing_Bisq_1_Signed_Account_Age" aria-hidden="true"></span><h3 id="method-4-importing-bisq-1-signed-account-age"> Method 4: Importing Bisq 1 Signed Account Age </h3>&#10;<p>Leverage the history of fiat accounts that completed the older signing process in <a href="../bisq-1/">Bisq 1</a>. The older the signed account, the more trustworthy the user is assumed to be (though still considered a weaker form of reputation than BSQ burn/bond). Follow the process displayed in the Bisq 2 Reputation section:</p>&#10;<ol>&#10;<li><strong>Step 1:</strong> Select the user profile in Bisq 2 for which you want to attach the reputation.</li>&#10;<li><strong>Step 2:</strong> Copy the <strong>Profile ID</strong> displayed. You will paste this into Bisq 1.</li>&#10;<li><strong>Step 3:</strong> Open <strong><a href="../bisq-1/">Bisq 1</a></strong> and go to `ACCOUNT` &gt; `NATIONAL CURRENCY ACCOUNTS`.&#10;<ol>&#10;<li>Select the oldest <em>signed</em> account you wish to use.</li>&#10;<li>Click the button <strong>`EXPORT SIGNED WITNESS FOR BISQ 2`</strong>.</li>&#10;<li>This copies the required JSON data (containing the proof signed with your Bisq 2 Profile ID) to your clipboard.</li>&#10;</ol></li>&#10;<li><strong>Step 4:</strong> Return to Bisq 2 and paste the JSON data from your clipboard into the text area provided ('Json data from Bisq 1').</li>&#10;<li><strong>Step 5:</strong> Click the <strong>`Request authorization`</strong> button.</li>&#10;</ol>&#10;<p><strong>Scoring Details:</strong></p>&#10;<ul>&#10;<li><strong>Minimum Age Required:</strong> Signed account must be at least <strong>61 days</strong> old.</li>&#10;<li><strong>Score:</strong> <strong>10 points</strong> per day of the signed account's age (Weight = 10).</li>&#10;<li><strong>Maximum Age Counted:</strong> 2000 days.</li>&#10;<li><strong>Maximum Score:</strong> Capped at <strong>20,000 points</strong> (10 points/day * 2000 days).</li>&#10;<li><strong>Which Account:</strong> Uses the age of your single <strong>oldest</strong> <a href="../bisq-1/">Bisq 1</a> <em>signed</em> fiat account. Scores are <strong>not</strong> cumulative across multiple signed accounts for this method. Importing from an older signed account later can replace a previous score from this method.</li>&#10;<li><strong>Limitation:</strong> Signed account age alone may <strong>not be enough</strong> for higher reputation tiers; combine with other methods.</li>&#10;</ul>&#10;<figure class="wiki-source-image" id="source-image-8"><a href="../../media/wiki/78698c9a25c9567a9d4149ae4b02fb46e383726530c4810e31ecd798b027a64d.png"><img alt="Importing signed account age involves exporting proof from a signed Bisq 1 account." decoding="async" height="399" loading="lazy" src="../../media/wiki/78698c9a25c9567a9d4149ae4b02fb46e383726530c4810e31ecd798b027a64d.png" width="565"></a><figcaption><p>Importing signed account age involves exporting proof from a signed <a href="../bisq-1/">Bisq 1</a> account.</p>&#10;<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p><br>&#10;</p>&#10;<span class="wiki-legacy-anchor" id="Reputation_Simulation_Tool" aria-hidden="true"></span><h2 id="reputation-simulation-tool"> Reputation Simulation Tool </h2>&#10;<p>Deciding how much <a href="../introduction-to-the-dao/">BSQ</a> to burn or bond can be complex. <a href="../bisq-2/">Bisq 2</a> provides a simulation tool (visible on the 'SCORE' tab for Burning/Bonding/Import methods) to help sellers estimate the reputation score impact of these actions.</p>&#10;<p>Find this tool within the <strong>`Reputation`</strong> section (accessible from the main left-hand menu). It helps visualize the immediate score increase and the potential score after the first year's doubling effect (for BSQ methods) or based on account age.</p>&#10;<figure class="wiki-source-image" id="source-image-9"><a href="../../media/wiki/be25fd666501baad767340bb00772d8ba76d6ccb6fc5ff59e3045b1af3419f43.png"><img alt="Simulating the reputation gained from burning BSQ." decoding="async" height="1348" loading="lazy" src="../../media/wiki/be25fd666501baad767340bb00772d8ba76d6ccb6fc5ff59e3045b1af3419f43.png" width="1924"></a><figcaption><p>Simulating the reputation gained from burning <a href="../introduction-to-the-dao/">BSQ</a>.</p>&#10;<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<figure class="wiki-source-image" id="source-image-10"><a href="../../media/wiki/6dbd80620dc007b503fea291e4c92125c216b1045dadea66df2fc5da4c5156b4.png"><img alt="Simulating the reputation gained from bonding BSQ." decoding="async" height="1348" loading="lazy" src="../../media/wiki/6dbd80620dc007b503fea291e4c92125c216b1045dadea66df2fc5da4c5156b4.png" width="1912"></a><figcaption><p>Simulating the reputation gained from bonding <a href="../introduction-to-the-dao/">BSQ</a>.</p>&#10;<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p><br>&#10;</p>&#10;<span class="wiki-legacy-anchor" id="What_Happens_if_a_Profile_is_Banned?" aria-hidden="true"></span><h2 id="what-happens-if-a-profile-is-banned"> What Happens if a Profile is Banned? </h2>&#10;<p>If a user's profile ID (which contains a public key hash tied to reputation) is banned by <a href="../bisq-2-roles/">moderators</a> for severe or repeated violations of Bisq trade protocols, <strong>all reputation associated with that specific profile ID is permanently lost</strong> and becomes unusable. The reputation score will no longer be visible or count towards rankings. Banning may also trigger consequences in <a href="../bisq-1/">Bisq 1</a> (e.g., <a href="../changing-your-onion-address/">onion address</a> ban, <a href="../introduction-to-the-dao/">BSQ</a> bond confiscation proposal via the <a href="../introduction-to-the-dao/">DAO</a>).</p>&#10;</div>
