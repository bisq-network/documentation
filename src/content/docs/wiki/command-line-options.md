<div class="wiki-recovered-article" lang="en"><p>Specifying <strong>command line options</strong> can enable additional non-default settings when <a href="../running-from-the-command-line/">running Bisq from the command line</a>.</p>&#10;<p>See a full list of available options <a href="https://github.com/bisq-network/bisq/blob/master/common/src/main/java/bisq/common/config/Config.java#L57" rel="noopener noreferrer">in the code</a>. This article covers more notable ones for typical use cases.</p>&#10;<span class="wiki-legacy-anchor" id="Specify_a_different_data_directory" aria-hidden="true"></span><h2 id="specify-a-different-data-directory"> Specify a different data directory </h2>&#10;<p>The default data directory Bisq uses is called "Bisq". All Bisq data is fully contained in it. The <a href="../data-directory/#default-locations">default path</a> of this data directory varies based on your operating system. To change the default path too, <a href="../command-line-options/#specify-a-different-data-directory-path">see below</a>.</p>&#10;<p>You can specify a different data directory with <code class="wiki-source-code" id="source-code-1">--appData=BisqTest</code> (change "BisqTest" to whatever you want; "Bisq" is the default) and Bisq will create a brand new data directory in the <a href="../data-directory/#default-locations">default path</a> with a new wallet, keys, onion address, etc (or use the existing data directory with that name if it's already there).</p>&#10;<p>You can use this option to run more than one instance of Bisq at once, which can be helpful to send funds from one Bisq instance to another when <a href="../switching-to-a-new-data-directory/#send-funds">switching to a new data directory</a>.</p>&#10;<p><a href="../command-line-options/#include-command-line-options-by-default">See below</a> for a suggestion on including this option automatically without having to specify it every time.</p>&#10;<span class="wiki-legacy-anchor" id="Specify_a_different_data_directory_path" aria-hidden="true"></span><h2 id="specify-a-different-data-directory-path"> Specify a different data directory path </h2>&#10;<p>If you'd like to change the default path for the data directory altogether (e.g. to store the data directory on another drive), run Bisq with <code class="wiki-source-code" id="source-code-2">--appDataDir=/external/hard/drive/path</code>.</p>&#10;<p><a href="../command-line-options/#include-command-line-options-by-default">See below</a> for a suggestion on including this option automatically without having to specify it every time.</p>&#10;<span class="wiki-legacy-anchor" id="Dump_delayed_payout_transactions" aria-hidden="true"></span><h2 id="dump-delayed-payout-transactions"> Dump delayed payout transactions </h2>&#10;<p>Add the <code class="wiki-source-code" id="source-code-3">--dumpDelayedPayoutTxs=true</code> option to dump delayed payout transactions in the following files in your data directory, inside the <code class="wiki-source-code" id="source-code-4">db</code> folder:</p>&#10;<ol>&#10;<li>delayed_payout_txs_closed.json</li>&#10;<li>delayed_payout_txs_pending.json</li>&#10;<li>delayed_payout_txs_failed.json</li>&#10;</ol>&#10;<span class="wiki-legacy-anchor" id="Specify_a_Bitcoin_node" aria-hidden="true"></span><h2 id="specify-a-bitcoin-node"> Specify a Bitcoin node </h2>&#10;<p>Sometimes Bisq cannot connect to the node specified in the interface at <code class="wiki-source-code" id="source-code-5">Settings</code> &gt; <code class="wiki-source-code" id="source-code-6">Network Info</code>, so starting Bisq with <code class="wiki-source-code" id="source-code-7">--btcNodes=&lt;node address&gt;</code> can help.</p>&#10;<p><a href="../command-line-options/#include-command-line-options-by-default">See below</a> for a suggestion on including this option automatically without having to specify it every time.</p>&#10;<span class="wiki-legacy-anchor" id="See_all_Bisq_trades" aria-hidden="true"></span><h2 id="see-all-bisq-trades"> See all Bisq trades </h2>&#10;<p>See all Bisq trades by running the <code class="wiki-source-code" id="source-code-8">--dumpStatistics=true</code> option. Then check out <code class="wiki-source-code" id="source-code-9">btc_mainnet/db/trade_statistics.json</code>.</p>&#10;<p><a href="../command-line-options/#include-command-line-options-by-default">See below</a> for a suggestion on including this option automatically without having to specify it every time.</p>&#10;<span class="wiki-legacy-anchor" id="Include_command-line_options_by_default" aria-hidden="true"></span><h2 id="include-command-line-options-by-default"> Include command-line options by default </h2>&#10;<p>If there are certain options you'd like to include every time you start Bisq, you can make a script that specifies them for you.</p>&#10;<p>For example, this script specifies an alternative data directory path on macOS:</p>&#10;<p><code>#!/bin/bash</code><br>&#10;<br>&#10;<code>/Applications/Bisq.app/Contents/MacOS/Bisq --appDataDir=/external/hard/drive/path</code></p>&#10;<p>Replace the Bisq executable path above with the <a href="../running-from-the-command-line/">one for your operating system</a> and specify the options you want to include. Then put the script somewhere in your system path so you can easily call it.</p>&#10;<p>Optionally, consider making a dummy directory in the default location to prevent Bisq from accidentally launching in its default mode. To do this, create a directory named "Bisq" in the default <a href="../data-directory/#default-locations">data directory path</a> for your operating system without any permissions.</p>&#10;<p>For example, on macOS:</p>&#10;<p><code>$ cd ~/Library/Application\ Support/</code><br>&#10;<code>$ mkdir Bisq</code><br>&#10;<code>$ chmod 000 Bisq</code></p>&#10;<p>In this way, since the system won't have write access in the default location, launching Bisq normally will fail, reminding you to launch Bisq with your script.</p>&#10;</div>
