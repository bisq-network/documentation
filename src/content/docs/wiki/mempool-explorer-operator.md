## Duties {#duties}

- Run an instance of [Mempool](https://github.com/mempool/mempool) with Bitcoin and Bisq networks enabled
- Make your Mempool Explorer instance available over HTTPS clearnet and Tor V3 HS onion, enable HSTS and DNSSEC
- Update the Bisq Pricenode code to contain the FQDN clearnet hostname of your Mempool Explorer
- Update the Bisq code to contain the FQDN clearnet hostname and Tor V3 HS onion of your Mempool Explorer
