## Core use case {#core-use-case}

a set of actions within Bisq required to successfully trade or manage funds

<span class="wiki-legacy-anchor" id="Critical_bug" aria-hidden="true">
</span>

## Critical bug {#critical-bug}

any issue that:

- impedes a user from completing a [core use case](../glossary/#core-use-case), or
- repeatedly lands users in support, or
- puts user funds or privacy at risk
