<div class="wiki-recovered-article" lang="en"><p>If you or a mediator require additional information on failed, pending, or closed transactions, run Bisq with the <code class="wiki-source-code" id="source-code-1">--dumpDelayedPayoutTxs=true</code> command line argument.</p>&#10;<p>The instructions below contain specific commands for each of the major desktop operating systems you can copy and paste into a terminal.</p>&#10;<h2 id="commands-to-dump-delayed-payout-transactions"> Commands to dump delayed payout transactions </h2>&#10;<span class="wiki-template-gap" role="note"><strong>[Unresolved template: Run_with_command_line_options]</strong> <code>{{Run_with_command_line_options|&lt;nowiki&gt;--dumpDelayedPayoutTxs=true&lt;/nowiki&gt;}}</code></span>&#10;<h2 id="where-to-find-the-delayed-payout-files"> Where to find the delayed payout files </h2>&#10;<p>Shortly after running one of the commands above, you will find 3 newly-created files in your Bisq data directory:</p>&#10;<ol>&#10;<li><code class="wiki-source-code" id="source-code-3">delayed_payout_txs_closed.json</code></li>&#10;<li><code class="wiki-source-code" id="source-code-4">delayed_payout_txs_pending.json</code></li>&#10;<li><code class="wiki-source-code" id="source-code-5">delayed_payout_txs_failed.json</code></li>&#10;</ol>&#10;<p>The location of your data directory depends on what operating system you're using:</p>&#10;<span class="wiki-template-gap" role="note"><strong>[Unresolved template: Default_data_directory_locations]</strong> <code>{{Default_data_directory_locations}}</code></span>&#10;<h2 id="next-steps"> Next steps </h2>&#10;<p>You can broadcast the DPT through any online tx broadcaster service, like that of <a href="https://mempool.space/tx/push" rel="noopener noreferrer">mempool.space</a>.</p>&#10;<p>Publishing the DPT will enable the arbitration process, where communication with RefundAgent will be necessary in order to manage the dispute. Chances are that if you need to manually broadcast the DPT, you cannot communicate with RefundAgent through the normal arbitration chat, so you will have to contact him through matrix, <a href="../finding-your-arbitrator/">Finding your arbitrator</a></p>&#10;</div>
