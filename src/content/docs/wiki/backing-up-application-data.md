<div class="wiki-recovered-article" lang="en"><p><strong>Backing up</strong> your Bisq data is crucial to ensure you can retain control over trades, disputes, payment accounts, and funds in case of issues with your machine (e.g., drive failure) or Bisq itself (e.g., critical bugs).</p>&#10;<p>All Bisq data is stored right on your computer—it's never stored (or even sent) to a central server, so backing it up is your job.</p>&#10;<p>To see how to <em>restore</em> data to Bisq, see <a href="../restoring-application-data/">Restoring application data</a>.</p>&#10;<h2 id="back-up-the-entire-bisq-data-directory"> Back up the entire Bisq data directory </h2>&#10;<p>The safest, quickest, easiest, and most comprehensive thing you can do to safeguard your data is to back up the whole data directory at regular intervals. See the various elements of the data directory detailed <a href="../data-directory/#data-directory-structure">here</a>.</p>&#10;<p>In addition, to make restoring payment accounts easier, you may want to back up an <a href="../backing-up-application-data/#back-up-payment-accounts">export of your payment accounts</a>.</p>&#10;<h3 id="while-bisq-is-running"> While Bisq is running </h3>&#10;<p>Go to <code class="wiki-source-code" id="source-code-1">Account</code> &gt; <code class="wiki-source-code" id="source-code-2">Backup</code> and put in a location for your backup to be exported to (note that this section is titled "Backup wallet" in the software but it actually exports the entire data directory).</p>&#10;<figure class="wiki-source-image" id="source-image-1"><a href="../../media/wiki/26782ecb73f26760dab0f720c3d9eb40fc2f8c1112e55c8bd1360d3ecf153449.png"><img alt="Data directory backup screen." decoding="async" height="710" loading="lazy" src="../../media/wiki/26782ecb73f26760dab0f720c3d9eb40fc2f8c1112e55c8bd1360d3ecf153449.png" width="1200"></a><figcaption>Data directory backup screen.<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>&#10;<h3 id="while-bisq-is-closed"> While Bisq is closed  </h3>&#10;<p>When Bisq is closed, you can simply copy the entire data directory and paste it somewhere safe. Find the location of your data directory by clicking on the <code class="wiki-source-code" id="source-code-3">Open Directory</code> button (see screenshot above) or see <a href="../data-directory/#default-locations">data directory locations here</a>.</p>&#10;<h3 id="encrypt-your-backup"> Encrypt your backup </h3>&#10;<p><strong>Backup files are not encrypted.</strong> If you’ve set a wallet password, your wallet files will be encrypted, but all your other data will <em>not</em> be encrypted.</p>&#10;<p>We recommend encrypting the whole backup folder with something like gpg, 7-Zip, Cryptomator, etc.</p>&#10;<h2 id="back-up-payment-accounts"> Back up payment accounts </h2>&#10;<p>If you just want to back up your payment accounts, export them from <code class="wiki-source-code" id="source-code-4">Account</code> &gt; <code class="wiki-source-code" id="source-code-5">National Currency Accounts</code>.</p>&#10;<p>Be advised: exporting your accounts this way only exports metadata. <strong>Aging and signing status are not included</strong>. To include <a href="../account-limits/">account aging and signing status</a>, you also need to save the <code class="wiki-source-code" id="source-code-6">btc_mainnet/keys/sig.key</code> file from your <a href="../data-directory/">data directory</a>.</p>&#10;<p>Because of the way <a href="../restoring-application-data/#restore-payment-accounts">restoring payment accounts</a> works, it's best for most users to back up the whole data directory <em>and</em> back up a payment account export.</p>&#10;<figure class="wiki-source-image" id="source-image-2"><a href="../../media/wiki/b159a14c41bd5d2a2ac88fcc2add65d497bfe93310ca2f9c7f5246c6f6321d36.png"><img alt="Export fiat payment accounts here. You can export altcoin accounts from the Altcoin Accounts tab." decoding="async" height="710" loading="lazy" src="../../media/wiki/b159a14c41bd5d2a2ac88fcc2add65d497bfe93310ca2f9c7f5246c6f6321d36.png" width="1200"></a><figcaption>Export fiat payment accounts here. You can export altcoin accounts from the Altcoin Accounts tab.<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>&#10;<h2 id="back-up-your-wallet-seed"> Back up your wallet seed </h2>&#10;<p>Please be sure to <a href="../backing-up-your-wallet-seed/">properly back up your wallet seed</a>.</p>&#10;<h2 id="export-tor-state"> Export Tor state </h2>&#10;<p>If you want to carry over a particular onion address (and keep your local reputation), you can replace the <code class="wiki-source-code" id="source-code-7">btc_mainnet/tor/hiddenservice</code> folder in your data directory with the one from your backup.</p>&#10;<h2 id="export-trade-history"> Export trade history </h2>&#10;<p>In <code class="wiki-source-code" id="source-code-8">Portfolio</code> &gt; <code class="wiki-source-code" id="source-code-9">History</code> you'll find an <code class="wiki-source-code" id="source-code-10">Export to CSV</code> button to export your trade history.</p>&#10;<p>There's no way to import this data back into Bisq, but it can be useful to have a copy of this data for yourself for record-keeping, analysis, etc.</p>&#10;<h2 id="export-transaction-history"> Export transaction history </h2>&#10;<p>In <code class="wiki-source-code" id="source-code-11">Funds</code> &gt; <code class="wiki-source-code" id="source-code-12">Transactions</code> you'll find an <code class="wiki-source-code" id="source-code-13">Export to CSV</code> button to export your trade history.</p>&#10;<p>There's no way to import this data back into Bisq, but it can be useful to have a copy of this data for yourself for record-keeping, analysis, etc.</p>&#10;<h2 id="automatic-backup-with-cyclic-redundancy"> Automatic backup with cyclic redundancy </h2>&#10;<p>Bisq doesn't directly implement a scheduled backup feature, but you can set up an <a href="../automatic-backup-script/">automatic backup routine</a> to store a versioned history of your data directory in a compact way.</p>&#10;</div>
