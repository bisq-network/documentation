<div class="wiki-recovered-article" lang="en"><p>The Security Team is responsible for keeping an eye on Bisq's needs for security - hunt bugs, design counter measures, be a point of contact for security related topics.</p>&#10;<h2 id="roles"> Roles </h2>&#10;<ul>&#10;<li><a href="../security-team-lead/">Security Team Lead</a></li>&#10;</ul>&#10;<h2 id="infrastructure">Infrastructure</h2>&#10;<h3 id="github">GitHub</h3>&#10;<h4 id="team">Team</h4>&#10;<a href="https://github.com/orgs/bisq-network/teams/security" rel="noopener noreferrer">@bisq-network/security</a>&#10;<h4 id="repositories">Repositories</h4>&#10;<ul>&#10;<li><a href="https://github.com/bisq-network/security" rel="noopener noreferrer">https://github.com/bisq-network/security</a></li>&#10;</ul>&#10;<h3 id="chat"> Chat </h3>&#10;<ul>&#10;<li>TBD</li>&#10;</ul>&#10;<h2 id="goals"> Goals </h2>&#10;<h3 id="what-does-security-in-security-team-mean"> What does "security" in "Security Team" mean </h3>&#10;<ul>&#10;<li>Optimize information footprint</li>&#10;<li>Hardening of the Bisq app, services, protocols, down to code</li>&#10;</ul>&#10;<h3 id="duties"> Duties </h3>&#10;<ul>&#10;<li>Maintain an overview of Bisq from a security perspective</li>&#10;<li>Find attack vectors</li>&#10;<li>Design counter strategies</li>&#10;<li>Act as a think-tank, consortium and knowledge base for security-related stuff</li>&#10;<li>Firefighting</li>&#10;<li>No feature implementation work, because that is the realm of either <a href="../dev-team/">Dev Team</a> or <a href="../ops-team/">Ops Team</a>.</li>&#10;</ul>&#10;<h3 id="mode-of-operation"> Mode of operation </h3>&#10;<p>Results and work of the security team might not be shared with the general public immediately. Simply because it makes no sense to publish a security vulnerability before it has been patched up. This is why the various channels of communication are invite-only.</p>&#10;<h3 id="general-roadmap"> General Roadmap </h3>&#10;<ul>&#10;<li>Do security audits. Use appropriate tools to find vulnerabilities. Even leave the beaten path of Java if it is the reasonable thing to do.</li>&#10;<li>Up testing efforts. Technical dept is causing all sorts of issues already. More test coverage might just reveal more vulnerabilities.</li>&#10;<li>Implement means for a responsible disclosure process, either fed by the efforts of the security team or fed by external sources.</li>&#10;<li>Create and maintain an overview of Bisq from a security perspective</li>&#10;<li>Prioritize and design countermeasures to be implemented by the <a href="../dev-team/">Dev Team</a>/<a href="../ops-team/">Ops Team</a></li>&#10;</ul>&#10;</div>
