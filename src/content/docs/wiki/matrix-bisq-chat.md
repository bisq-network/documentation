Matrix is a messaging platform used by Bisq for discussions of all things related to Bisq. It is also the place for Bisq users to access support agents with any questions they might have.

Matrix replaced Keybase as the main Bisq messaging platform around January 2022. If you are still using Keybase it is recommended to move over to Matrix by visiting [bisq.chat](https://bisq.chat/).

</span>

## Matrix {#matrix}

[Matrix.org](http://www.matrix.org) is a secure, decentralized, real-time communication tool [replacing Keybase](https://github.com/bisq-network/proposals/issues/355), the tool previously used by Bisq prior to 2022. Bisq self-hosts [bisq.chat](https://bisq.chat/), a Matrix team server, which takes a step further on the grade of censorship-resistance and privacy.

### Web interface {#web-interface}

Matrix can be used as a web based app. That\'s a big advantage, specially for users only requiring occasional support and who don\'t need to keep on the day to day conversations. To start using \[bisq.chat\] just click the link and you\'ll see a page like this:

<figure class="wiki-source-image" id="source-image-1"><a href="../../media/wiki/c12bdd5aa955a9683463eb5883764227fe16a53ae1a6795c4ff9852cd64b38a7.png"><img alt="Matrix 1.png" decoding="async" height="394" loading="lazy" src="../../media/wiki/c12bdd5aa955a9683463eb5883764227fe16a53ae1a6795c4ff9852cd64b38a7.png" width="496"></a><figcaption>Matrix 1.png<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>

Click *continue* and many Matrix clients will be displayed. Select Element, which is one of the most popular and can be used without installing software. Click the *continue in your browser* button and the [web app Element](https://app.element.io/#/room/#bisq:bitcoin.kyoto) will load. Click *join* and *create account*, as we suppose you don\'t have a matrix account yet. Next image shows fields needed to host the account at matrix.org. There are other hosts requiring different data to join.

#### Joining channels {#joining-channels}

Once the matrix.org hosting account has been created, you\'ll see the [General](https://matrix.to/#/#bisq-general:matrix.org) and [Support](https://matrix.to/#/#bisq-support:matrix.org) channel.\
Click on the *+* sign on *Rooms* and then *Explore rooms* to join other channels.

<figure class="wiki-source-image" id="source-image-3"><a href="../../media/wiki/10abbdcc5123fabf2acc8e8079236daeae2ac9fd466e73c88a161131419bac4a.png"><img alt="Matrix web main screen.png" decoding="async" height="684" loading="lazy" src="../../media/wiki/10abbdcc5123fabf2acc8e8079236daeae2ac9fd466e73c88a161131419bac4a.png" width="1000"></a><figcaption>Matrix web main screen.png<br><small>Historical thumbnail; original resolution not recovered. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>

### Installing Element {#installing-element}

To install Element on your desktop, go to [https://element.io/get-started#download](https://element.io/get-started#download), select your OS and follow the instructions. Check other clients and platforms [here](https://matrix.org/docs/projects/try-matrix-now/).\
You can also download and install Element on Android or iOS through their app stores.
