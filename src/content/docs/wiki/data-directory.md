<div class="wiki-recovered-article" lang="en"><p>The <strong>data directory</strong> is where all of Bisq's application data files (including wallet, account details, trade history, and settings) are stored locally on your computer.</p>&#10;<p>It is crucial that you <a href="../backing-up-application-data/">back up this directory</a> regularly to prevent data loss.</p>&#10;<aside class="wiki-admonition" role="note"><p><strong>Note</strong></p><p><strong>Version Context:</strong> The directory structure described below is primarily based on Bisq v1. The location and general purpose remain similar in <a href="../bisq-2/">Bisq 2</a>, although specific file organization within subdirectories like `db/` or `keys/` might differ due to features like multiple <a href="../identity/">identities</a>.</p>&#10;</aside>&#10;<h2 id="data-directory-structure"> Data directory structure </h2>&#10;<p>Notable items typically found within the main Bisq data directory:</p>&#10;<ul>&#10;<li>`bisq.log` - The main log file containing recent application activity, often helpful for debugging. Be cautious sharing it publicly as it may contain private information.</li>&#10;<li>`bisq.properties` - A configuration file where the full list of <a href="https://github.com/bisq-network/bisq/blob/master/common/src/main/java/bisq/common/config/Config.java#L57" rel="noopener noreferrer">command-line options</a> can be permanently set (one per line in `&lt;option&gt;=&lt;value&gt;` format, e.g., `dumpStatistics=true`), avoiding the need to specify them each time Bisq is launched.</li>&#10;<li>`btc_mainnet/` - The primary subdirectory containing most network-specific operational data.&#10;<ul>&#10;<li>`keys/` - Stores cryptographic keys used for signing P2P network messages and for <a href="../account-limits/">signing and aging</a> payment accounts (in Bisq v1).</li>&#10;<li>`db/` - Contains various user data (e.g., closed trades, DAO state) and network data. <strong>It is strongly discouraged to manually edit any files in this directory.</strong></li>&#10;<li>`tor/` - Holds state data for the built-in <span class="wiki-link-gap">Tor <small>[unrecovered article: Tor]</small></span> connection. The `hiddenservice/` folder within this directory contains the keys determining your Bisq <a href="../changing-your-onion-address/">onion address</a>.</li>&#10;<li>`wallet/` - Contains your BTC and <a href="../bsq/">BSQ</a> wallet files (`bisq_BTC.wallet`, `bisq_BSQ.wallet`), rolling backups, and the SPV chain file (`<a href="../resyncing-spv-file/">bisq.spvchain</a>`).</li>&#10;</ul></li>&#10;</ul>&#10;<h2 id="default-locations"> Default locations </h2>&#10;<p>The default location of the main Bisq data directory varies by operating system. The exact path can usually be found easily from within the application itself (see below), but the standard defaults are listed by the template:</p>&#10;<span class="wiki-template-gap" role="note"><strong>[Unresolved template: Default_data_directory_locations]</strong> <code>{{Default_data_directory_locations}}</code></span>&#10;<h3 id="opening-directory-from-bisq"> Opening Directory from Bisq </h3>&#10;<p>The easiest way to find and open your specific data directory is directly through the Bisq application:</p>&#10;<ol>&#10;<li>Go to the `Account` tab.</li>&#10;<li>Select the `Backup` sub-tab.</li>&#10;<li>Click the button labeled <strong>`OPEN DIRECTORY`</strong>.</li>&#10;</ol>&#10;<figure class="wiki-source-image" id="source-image-1"><a href="../../media/wiki/fae5ef7e526b9c28081cfb4c30b9df56f1c75b39f5edbaf3512aec689ecacfc5.png"><img alt="Clicking the 'OPEN DIRECTORY' button on the Account &gt; Backup screen." decoding="async" height="2590" loading="lazy" src="../../media/wiki/fae5ef7e526b9c28081cfb4c30b9df56f1c75b39f5edbaf3512aec689ecacfc5.png" width="4320"></a><figcaption>Clicking the 'OPEN DIRECTORY' button on the Account &gt; Backup screen.<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<div>&#10;</div>&#10;<p>This will open your system's file explorer directly to the Bisq data directory, bypassing the need to manually navigate hidden folders or different paths depending on your OS.</p>&#10;<h2 id="see-also"> See also </h2>&#10;<ul>&#10;<li><a href="../backing-up-application-data/">Backing up application data</a></li>&#10;<li><a href="../restoring-application-data/">Restoring application data</a></li>&#10;<li><a href="../switching-to-a-new-data-directory/">Switching to a new data directory</a></li>&#10;<li><a href="../running-from-the-command-line/">Running from the command line</a></li>&#10;</ul>&#10;</div>
