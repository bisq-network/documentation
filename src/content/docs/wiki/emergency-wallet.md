<div class="wiki-recovered-article" lang="en"><h2 id="warning"> Warning </h2>&#10;<p>Ask for help on <a href="../user-support/#via-matrix-bisq-chat">Matrix</a> to make sure this is the best solution to your issue. Use under your own risk.</p>&#10;<h2 id="backup"> Backup </h2>&#10;<p>Make a <a href="../backing-up-application-data/">backup</a> of your Bisq data before using the emergency wallet.</p>&#10;<h2 id="emergency-wallet"> Emergency wallet </h2>&#10;<p>This tool allows you to send all funds to a BTC or BSQ address. It should be used only when Bisq wallet is corrupted. You can access to external wallet through shortkey <code class="wiki-source-code" id="source-code-1">'Ctrl + e' or 'alt + e' or 'cmd + e'</code> for BTC, and <code class="wiki-source-code" id="source-code-2">'Ctrl + b' or 'alt + b' or 'cmd + b'</code> for BSQ.</p>&#10;<figure class="wiki-image-gap" id="source-image-1"><p><strong>Image not recovered: Emergency Wallet.png</strong></p><p>The original file is unavailable in this local recovery.</p></figure>&#10;<div>&#10;</div>&#10;<h2 id="restore-wallet-from-seed"> Restore wallet from seed </h2>&#10;<p>If the emergency wallet tool produces a transaction that fails to broadcast (you can see that at <em>Funds &gt; Transactions</em>) you can import private keys to a <a href="../switching-to-a-new-data-directory/">new Bisq instance</a> at <em>Accounts &gt; Wallet Seed - Restore wallet from seed</em>. Importing seeds to an external wallet should be used only if this method fails, and is extremely recommended to report it to support.</p>&#10;</div>
