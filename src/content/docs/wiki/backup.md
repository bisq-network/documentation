## Backup strategies{#backup-strategies}

<span class="wiki-legacy-anchor" id="Manual_backup" aria-hidden="true">
</span>

### Manual backup {#manual-backup}

Bisq1 has a manually triggered backup feature that saves a copy of the whole contents of the data directory to a selected location: [backing up application data](../backing-up-application-data/)

Bisq2 has a very similar feature that can be reached under Support > Resources > Backup, and works in a similar manner.

<span class="wiki-legacy-anchor" id="Built-in_automatic_backup" aria-hidden="true">
</span>

### Built-in automatic backup {#built-in-automatic-backup}

Bisq2 extends the existing manual backup, and also provides a feature to create versioned backups: [automatic backup](../automatic-backup/)

<span class="wiki-legacy-anchor" id="Custom_automatic_backup_scripts" aria-hidden="true">
</span>

### Custom automatic backup scripts {#custom-automatic-backup-scripts}

A standalone script is also available to create versioned backups on Windows, MacOS and Linux, of the essential database files of both Bisq1 and Bisq2: [automatic backup script](../automatic-backup-script/)
