<div class="wiki-recovered-article" lang="en"><p>A <strong>Pricenode Operator</strong> runs one or more <a href="../pricenode/">pricenode</a> instance and keeps them updated.</p>

<span class="wiki-legacy-anchor" id="Duties" aria-hidden="true"></span><h2 id="duties"> Duties </h2>
<ul>
<li>Setup and maintain a suitable hosting environment for the pricenode</li>
<li>Operate your pricenode using the <a href="https://github.com/bisq-network/bisq/tree/master/pricenode#how-to-deploy-for-production" rel="noopener noreferrer">current pricenode documentation</a></li>
<li>Run collectd with the <a href="https://github.com/bisq-network/bisq/tree/master/pricenode#Monitoring" rel="noopener noreferrer">current monitoring documentation</a> from bisq-monitoring operator</li>
<li>Maintain your Tor onion hostname in the <a href="https://github.com/bisq-network/bisq/blob/master/core/src/main/java/bisq/core/provider/ProvidersRepository.java#L38" rel="noopener noreferrer">Bisq pricenode provider repository</a></li>
</ul>
<span class="wiki-legacy-anchor" id="Rights" aria-hidden="true"></span><h2 id="rights"> Rights </h2>
<ul>
<li>Claim 130 USD compensation each cycle</li>
</ul>
