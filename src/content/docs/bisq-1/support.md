For an active trade, start with [trade chat or mediation](../dispute-help/). For an application problem, use [bisq.chat](https://bisq.chat/) and select the support room. Never reveal seed words, private keys, passwords or a full application backup to someone offering help.

## Ask a useful support question

Include Bisq version, operating system, exact error text, when it happened and whether a trade is active. Explain what you already tried. Share transaction IDs only when needed and understand they expose public financial links. Redact bank details, names and unrelated balances from screenshots and logs.

Unsolicited private messages, lookalike names, executable attachments and requests to enter a seed on a website are warning signs. Verify the full account identity through the public room and, for trade agents, [the assigned mediator](../finding-your-mediator/) or [arbitrator](../finding-your-arbitrator/). A chat display name alone is not authentication.

## Join Matrix

Bisq moved its main community discussion from Keybase to Matrix around 2022. Follow **bisq.chat** to the current space/rooms rather than relying on an old room alias. You can use a compatible browser client such as Element or a desktop/mobile client; account creation requirements depend on the homeserver you choose.

After joining the Bisq space, select its support room. To discover other rooms, use the client's **Explore rooms** control (historically under the room-list plus button or space menu). Client layouts and homeserver requirements change, so the screenshots below are orientation rather than a current signup contract.

## Report a software bug

Use [bisq-network/bisq issues](https://github.com/bisq-network/bisq/issues) for a reproducible Bisq 1 software problem. Include the version, reproduction steps and a minimal redacted log excerpt. A bug report is not automatically a reimbursement request; [fee reimbursement](../reimbursements/) has a separate evidence template.

The community forum, Reddit, Telegram, Nostr and other channels can provide discussion and announcements. Start from [the official contact page](https://bisq.network/contact/) for current links. The old article warns particularly about unsolicited “support” messages on Reddit/Telegram; do not infer that another platform is impersonation-free.

## Help someone else

Keep advice specific to product and release, verify transaction state before suggesting a repair, and never ask for wallet secrets. Current recovery steps can differ sharply from a screenshot or older tutorial. For contributing support or documentation, read [the contributor guide](../../contribute/getting-started/).
