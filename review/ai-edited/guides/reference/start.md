## Introduction

Bisq is open-source software for peer-to-peer bitcoin trading. Participants run the software and interact with each other rather than depositing funds with a central exchange. The exact security, payment and dispute process depends on the application and trade protocol. Read [which app to choose](../../start/choose-bisq/) before following a procedure.

Bisq 1 uses a trade process involving a multisignature deposit and dispute mechanisms. Bisq 2 supports distinct protocols, including Bisq Easy. A feature or limit from one is not automatically applicable to the other. Network privacy and self-custody reduce certain dependencies, but they do not eliminate counterparty, software, payment, network or user-error risks.
