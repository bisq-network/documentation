<div class="wiki-recovered-article" lang="en"><p><strong>Payment accounts</strong> indicate the method by which Bisq trades are to be settled. You must create a national currency account to trade bitcoin for national currencies or an altcoin account to trade altcoins for bitcoin.</p>&#10;<span class="wiki-legacy-anchor" id="Creating_a_national_currency_account" aria-hidden="true"></span><h2 id="creating-a-national-currency-account"> Creating a national currency account </h2>&#10;<p>Before creating a national currency account, notice that we cannot take any offers. The buttons to take offers are disabled, and if we try to click any of them, Bisq will tell us we need to create a payment account first.</p>&#10;<figure class="wiki-source-image" id="source-image-1"><a href="../../media/wiki/ac4951d4e10bd9ad03dd284a8b475e00018ff41ed51bea312de8989925d765b7.png"><img alt="BuyBitcoinscreen.png" decoding="async" height="559" loading="lazy" src="../../media/wiki/ac4951d4e10bd9ad03dd284a8b475e00018ff41ed51bea312de8989925d765b7.png" width="942"></a><figcaption>BuyBitcoinscreen.png<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p><br>&#10;You can create a new national currency account in <code class="wiki-source-code" id="source-code-1">Account</code> &gt; <code class="wiki-source-code" id="source-code-2">National Currency Accounts</code>. Pick the payment account type from the drop-down and fill out the form. For more details on the various payment methods Bisq offers, see <a href="../payment-methods/">Payment methods</a>.</p>&#10;<p>Bisq will ask you for information required to set up the account in Bisq. <strong>Recall that all the information you put in here is stored locally</strong>, and only sent to your trading peer upon confirmation of the trade's deposit transaction. This is a stark contrast to typical exchange KYC, where personal information is stored in a central database honeypot indefinitely for various forms of harassment and surveillance.</p>&#10;<aside class="wiki-admonition" role="note"><p><strong>Warning</strong></p><p>Make sure all information you put in your payment account is correct, such that it matches what the other trader will see on their bank statement. <strong>Do NOT use fake names or initials.</strong> Doing so is a violation of <a href="../trading-rules/#do-not-confirm-payments-with-mismatching-details">trading rules</a>.</p>&#10;<p>Also: once you’ve created an account, you cannot edit its details (if you need to make a change, you’ll have to delete and add the account again). So make sure everything is correct the first time!</p>&#10;</aside>&#10;<figure class="wiki-source-image" id="source-image-2"><a href="../../media/wiki/e9337d10a4354a502d789e2310f0c3e78dc24c5c83adbf078f5b186070ecf489.png"><img alt="Accountsetup.png" decoding="async" height="562" loading="lazy" src="../../media/wiki/e9337d10a4354a502d789e2310f0c3e78dc24c5c83adbf078f5b186070ecf489.png" width="944"></a><figcaption>Accountsetup.png<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p><br>&#10;You don’t need to edit the Salt field. Account name is a label you can set to make it easier to distinguish between other payment accounts you set up; only you will ever see, so there’s no right or wrong value for it.</p>&#10;<p>Once you're done, click <code class="wiki-source-code" id="source-code-3">Save New Account</code>. Go back to the <code class="wiki-source-code" id="source-code-4">Buy BTC</code> screen and you'll see that offers requiring the payment method you just configured will now be enabled:</p>&#10;<figure class="wiki-source-image" id="source-image-3"><a href="../../media/wiki/b438c0e73f171e2e1c5cfe2bdb92e4c166f8b1dd0bdd67c718662d3a64a75510.png"><img alt="BuyBTC-accountenabled.png" decoding="async" height="558" loading="lazy" src="../../media/wiki/b438c0e73f171e2e1c5cfe2bdb92e4c166f8b1dd0bdd67c718662d3a64a75510.png" width="940"></a><figcaption>BuyBTC-accountenabled.png<br><small>Historical full-size recovered source. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;<p><br>&#10;</p>&#10;<span class="wiki-legacy-anchor" id="Notes" aria-hidden="true"></span><h3 id="notes"> Notes </h3>&#10;<p>If there are no offers in the payment method you prefer, don't hesitate to make your own offer. New Bisq peers come online all the time, and it only takes 2 to trade. Also, offer makers pay a lot less in fees!</p>&#10;<span class="wiki-legacy-anchor" id="Creating_an_altcoin_account" aria-hidden="true"></span><h2 id="creating-an-altcoin-account"> Creating an altcoin account </h2>&#10;<p>Creating an altcoin account is largely the same as creating a national currency account, but even simpler.</p>&#10;<p>Navigate to the <code class="wiki-source-code" id="source-code-5">Account</code> &gt; <code class="wiki-source-code" id="source-code-6">Altcoin Accounts</code>, click <code class="wiki-source-code" id="source-code-7">Add New Account</code>, pick the altcoin you'd like to trade in the drop-down, and fill out the form.</p>&#10;<span class="wiki-legacy-anchor" id="Special_requirements" aria-hidden="true"></span><h3 id="special-requirements"> Special requirements </h3>&#10;<p>Some altcoins have specific requirements. Monero, for example, requires that sellers be able to provide a transaction key in case of a dispute, which is not available in all XMR wallets. L-BTC buyers must use a wallet that shows the blinding key. <strong>Make sure to read any pop-ups carefully to make sure your trades go as smoothly as possible.</strong></p>&#10;<span class="wiki-legacy-anchor" id="Instant_accounts" aria-hidden="true"></span><h3 id="instant-accounts"> Instant accounts </h3>&#10;<p>By default, all altcoins trades on Bisq have trade periods of 1 day, but you can set up an Altcoins Instant account on Bisq for 1-hour trade periods. Just check the box in the payment account creation process.</p>&#10;<figure class="wiki-source-image" id="source-image-4"><a href="../../media/wiki/56845df3c24c031a28167b2cf01a160b540066e8800cbdbc3b094b256f2c24da.png"><img alt="Check this box to set up an Altcoins Instant account." decoding="async" height="592" loading="lazy" src="../../media/wiki/56845df3c24c031a28167b2cf01a160b540066e8800cbdbc3b094b256f2c24da.png" width="1000"></a><figcaption>Check this box to set up an Altcoins Instant account.<br><small>Historical thumbnail; original resolution not recovered. <a href="../../recovered-media/">Provenance catalogue</a>.</small></figcaption></figure>&#10;</div>
