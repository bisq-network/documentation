<div class="wiki-recovered-article" lang="en"><p>Sometimes, Bisq trades don't go smoothly, and <strong>dispute resolution</strong> is required to determine an outcome. Dispute resolution in <a href="../bisq-2/">Bisq 2</a> varies depending on the <a href="../trade-protocols/">trade protocol</a> that was used.</p>
<p>Most issues on Bisq are minor and easily resolved when traders communicate with each other. Mediation is intended to resolve the vast majority of remaining issues.</p>
<span class="wiki-legacy-anchor" id="Trade_Protocols" aria-hidden="true"></span><h2 id="trade-protocols"> Trade Protocols </h2>
<p><a href="../bisq-2/">Bisq 2</a> will offer users the choice of multiple <a href="../trade-protocols/">trade protocols</a>. A <a href="../trade-protocols/">trade protocol</a> serves as the fundamental framework for trading Bitcoin in a secure way. Each trade protocol presents its own set of advantages and trade-offs, including:</p>
<ul>
<li>Security mechanisms</li>
<li>Dispute mechanisms</li>
<li>Security deposit requirements</li>
</ul>
<p><a href="../bisq-2/">Bisq 2</a> offers users the flexibility to select the optimal protocol aligning with their requirements and preferences. All <a href="../trade-protocols/">trade protocols</a> will be accessible from the <a href="../bisq-2/">Bisq 2</a> application independently. Users will be able to switch between <a href="../trade-protocols/">trade protocols</a> for different trades should they wish.</p>
<span class="wiki-legacy-anchor" id="Bisq_Easy" aria-hidden="true"></span><h3 id="bisq-easy"> Bisq Easy </h3>
<p><a href="../bisq-easy/">Bisq Easy</a> is a <a href="../trade-protocols/">trade protocol</a> for <a href="../bisq-2/">Bisq 2</a>, designed to facilitate the acquisition of bitcoin with zero trade fees and without the requirement of a <a href="../security-deposit/">security deposit</a>. <a href="../bisq-easy/">Bisq Easy</a> is a social <a href="../trade-protocols/">trade protocol</a> intended for novice bitcoin buyers seeking a non-KYC option and aiming to be efficiently onboarded by experienced and knowledgeable sellers that are familiar with the Bisq platform.</p>
<p>Security mechanisms: <a href="../reputation/">Reputation</a> Dispute mechanisms: <a href="../dispute-resolution-in-bisq-2/#trade-chat">Trade Chat</a> and <a href="../dispute-resolution-in-bisq-2/#mediation-in-bisq-easy">Mediation (for Bisq Easy)</a></p>
<span class="wiki-legacy-anchor" id="Dispute_Options" aria-hidden="true"></span><h2 id="dispute-options"> Dispute Options </h2>
<p>The options available for dispute resolution in <a href="../bisq-2/">Bisq 2</a> vary depending on the <a href="../trade-protocols/">trade protocol</a> that was used. The various dispute resolution mechanisms available in <a href="../bisq-2/">Bisq 2</a> include:</p>
<span class="wiki-legacy-anchor" id="Trade_Chat" aria-hidden="true"></span><h3 id="trade-chat"> Trade Chat </h3>
<p>If you're having any issues completing a trade, or if you just want to keep your counterparty informed (e.g., in case you're delayed completing your end of the deal), you can send your counterparty a message through Bisq's end-to-end encrypted chat mechanism. This allows traders to communicate with each other throughout the course of a trade to resolve potential trade issues quickly without involving a third party like a <a href="../mediator/">mediator</a>.</p>
<span class="wiki-legacy-anchor" id="Mediation_in_Bisq_Easy" aria-hidden="true"></span><h3 id="mediation-in-bisq-easy"> Mediation in Bisq Easy </h3>
<p>Mediation is available within Bisq Easy at any time. You can initiate it by selecting the 'request mediation' link on the trade screen. A <a href="../mediator/">mediator</a> will then join the trade chat and gather information to assist as much as possible. Since Bisq Easy trades do not require a security deposit, the mediator's abilities are somewhat limited. However, they can still provide valuable assistance and, if necessary, ban traders.</p>
<span class="wiki-legacy-anchor" id="If_all_else_fails" aria-hidden="true"></span><h2 id="if-all-else-fails">If all else fails</h2>
<p>One advantage of a flat, decentralized governance structure that encourages user involvement is that no user should ever feel hindered from receiving a fair trade outcome because of a single individual's decision. Bisq isn't a black-box corporation with inscrutable processes. It's an open software project that is governed openly.</p>
<p>Therefore, for whatever reason, if the process above doesn't work for you, you can make a <a href="../making-a-reimbursement-request/">make a reimbursement request</a> yourself in the <a href="../dao-user-reference/#bisq-dao">Bisq DAO</a>. <strong>The <a href="../dao-user-reference/#bisq-dao">Bisq DAO</a>, not any single individual, is the ultimate arbiter of policy and decision-making for all things Bisq.</strong></p>
