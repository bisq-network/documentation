<div class="wiki-recovered-article" lang="en"><p>Bisq is a decentralized <span class="wiki-link-gap">peer-to-peer <small>[unrecovered article: P2P Network]</small></span> bitcoin exchange network that you access via software running on your own computer. It enables secure, private, and censorship-resistant trading directly with other users, without relying on intermediaries.</p>&#10;<p>Bisq offers two software versions providing different trading experiences:</p>&#10;<span class="wiki-legacy-anchor" id="Bisq_1" aria-hidden="true"></span><h2 id="bisq-1"> Bisq 1 </h2>&#10;<p><a href="../bisq-1/">Bisq 1</a> is the original, well-established peer-to-peer exchange platform launched in 2016 (initially as BitSquare). It allows users to trade Bitcoin for fiat currencies and various altcoins using a robust <a href="../security-deposit/">multisig deposit system</a> for security between strangers. Individual trade sizes on Bisq 1 can reach up to <span class="wiki-template-gap" role="note"><strong>[Unresolved template: MaxTradeSizeBisq1]</strong> <code>{{MaxTradeSizeBisq1}}</code></span> for fiat trades and <span class="wiki-template-gap" role="note"><strong>[Unresolved template: MaxTradeSizeAltcoin]</strong> <code>{{MaxTradeSizeAltcoin}}</code></span> for altcoin trades.</p>&#10;<p><strong><a href="../bisq-1/">Learn more about Bisq 1</a></strong></p>&#10;<span class="wiki-legacy-anchor" id="Bisq_2" aria-hidden="true"></span><h2 id="bisq-2"> Bisq 2 </h2>&#10;<p>Launched in 2024, <a href="../bisq-2/">Bisq 2</a> is the next-generation platform designed to support multiple <a href="../trade-protocols/">trade protocols</a>. The first, and currently primary, protocol available is <a href="../bisq-easy/">Bisq Easy</a>.</p>&#10;<p><a href="../bisq-easy/">Bisq Easy</a> facilitates peer-to-peer Bitcoin-fiat trades with security based on seller <a href="../reputation/">reputation</a>, rather than deposits. It features no trading fees and no deposit requirements, making it accessible for smaller trades up to the equivalent of 600 USD (or <span class="wiki-template-gap" role="note"><strong>[Unresolved template: MaxBisqEasyTrade]</strong> <code>{{MaxBisqEasyTrade}}</code></span>). It is positioned as a simpler alternative for users, especially those new to Bisq or making smaller fiat trades.</p>&#10;<p><strong><a href="../bisq-2/">Learn more about Bisq 2 &amp; Bisq Easy</a></strong></p>&#10;</div>
