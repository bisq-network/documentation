<div class="wiki-recovered-article" lang="en"><p>This article covers some tactics for <strong>troubleshooting wallet issues</strong> to address incorrect balance showing, missing transactions, and other strange inconsistencies.</p>&#10;<span class="wiki-legacy-anchor" id="Re-sync_SPV_chain" aria-hidden="true"></span><h2 id="re-sync-spv-chain"> Re-sync SPV chain </h2>&#10;<p>The SPV file is a collection of data from the Bitcoin blockchain that tells Bisq your wallet’s balances. All data in the file is available on the Bitcoin network. Resyncing this file just forces Bisq to resync with the Bitcoin network and fetch the data it needs to determine your wallet state again.</p>&#10;<p>See how to initiate an SPV resync <a href="../resyncing-spv-file/">here</a>.</p>&#10;<span class="wiki-legacy-anchor" id="Restore_a_wallet_backup" aria-hidden="true"></span><h2 id="restore-a-wallet-backup"> Restore a wallet backup </h2>&#10;<p>If issues persist, you can try to restore a wallet backup file from the <code class="wiki-source-code" id="source-code-1">btc_mainnet/wallet/backup/backups_bisq_BTC_wallet/</code> folder of your <a href="../data-directory/">data directory</a>.</p>&#10;<p>This folder holds your most recent wallet backups made on a rolling basis. Replace the <code class="wiki-source-code" id="source-code-2">bisq_BTC.wallet</code> file in <code class="wiki-source-code" id="source-code-3">btc_mainnet/wallet/</code> with a recent wallet backup file and rename it to <code class="wiki-source-code" id="source-code-4">bisq_BTC.wallet</code>. You will also need to resync the SPV chain when restoring a backup, so be sure to also delete <code class="wiki-source-code" id="source-code-5">bisq.spvchain</code>.</p>&#10;<p>Start Bisq and see if your issue is fixed. If not, repeat with another wallet backup file.</p>&#10;<span class="wiki-legacy-anchor" id="Switch_to_a_new_data_directory" aria-hidden="true"></span><h2 id="switch-to-a-new-data-directory"> Switch to a new data directory </h2>&#10;<p>If neither re-syncing the SPV chain nor restoring a wallet backup solves the issue, you might have a corrupted wallet.</p>&#10;<p>In this case, it’s best to <a href="../create-a-new-wallet-for-your-data-directory/">create a new wallet</a>.</p>&#10;</div>
