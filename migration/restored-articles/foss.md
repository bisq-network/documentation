<div class="wiki-recovered-article" lang="en"><p>Free and open-source software (FOSS) is a term used to refer to groups of software consisting of both free software and open-source software where anyone is freely licensed to use, copy, study, and change the software in any way, and the source code is openly shared so that people are encouraged to voluntarily improve the design of the software. This is in contrast to proprietary software, where the software is under restrictive copyright licensing and the source code is usually hidden from the users.</p>&#10;<p><span class="wiki-link-gap">Bitcoin <small>[unrecovered article: Bitcoin]</small></span> and <span class="wiki-link-gap">Linux <small>[unrecovered article: Linux]</small></span> are examples of successful FOSS projects.</p>&#10;<p>Bisq is FOSS.</p>&#10;</div>
