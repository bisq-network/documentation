== Duties ==
* Perform [https://docs.bisq.network/roles.html#common-duties duties common to all roles]
* Merge pull requests per the [[Development Process]]
* Manage critical bugs per the [[Critical Bugs]] process

== Rights ==
* Admin access to the bisq-network/bisq repository
* Write access to the [[Critical Bugs#Board|critical bugs board]]
